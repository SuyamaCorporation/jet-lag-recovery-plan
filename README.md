# 02 - 時差ボケ回復プランナー

**ビルド日**: 2026-11-03
**カテゴリ**: practical
**slug**: jet-lag-recovery-plan

## 概要
出発地・到着地のタイムゾーン（UTC±）と到着日時を入力すると、時差ボケの回復スケジュールを日別に生成。光照射・睡眠調整・メラトニンタイミングを時系列で提案します。

## 機能
- 出発地・到着地のタイムゾーン選択（UTC-12〜UTC+12）
- 東向き/西向き渡航方向の自動判定（西向きの方が回復しやすいことを反映）
- 日別回復スケジュール生成（就寝・起床・光照射・メラトニン目安時刻）
- 時差・方向・回復日数のサマリ表示
- 時系列順体内時計調整ガイダンス（1.5〜2時間/日ペース）
- 到着日・回復完了日をハイライト表示
